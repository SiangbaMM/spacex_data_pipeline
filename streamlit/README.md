# SpaceX Data Dashboard

A Streamlit dashboard application that visualizes data from the SpaceX data pipeline fact tables.

## Features

- **Multi-fact Table Support**: View data from three different fact tables:

  - Launch Data: Information about SpaceX launches, success rates, and payload metrics
  - Payload Data: Details about payloads, their types, orbits, and delivery success
  - Starlink Data: Information about Starlink satellites, their orbital status, and positions

- **Interactive Visualizations**:

  - Timeline charts
  - Success rate metrics
  - Distribution pie charts
  - Geographic maps for satellite positions
  - Scatter plots for orbital parameters

- **Filtering Capabilities**:
  - Date range filtering
  - Data limit controls
  - Environment selection (Development, UAT, Production)

## Setup

1. Install the required packages:

```bash
pip install -r requirements.txt
```

2. Set up environment variables (optional):
   - Create a `.env` file in the streamlit directory with the following variables:
   ```
   SNOWFLAKE_ACCOUNT=your_account
   SNOWFLAKE_USER=your_user
   SNOWFLAKE_PASSWORD=your_password
   SNOWFLAKE_ROLE=your_role
   SNOWFLAKE_WAREHOUSE=your_warehouse
   SNOWFLAKE_DATABASE=your_database
   SNOWFLAKE_SCHEMA=your_schema
   ```
   - If not provided, the app will use default values from the profiles.yml file

## Running the Dashboard

To run the dashboard:

```bash
cd streamlit
streamlit run spacex_dashboard.py
```

The dashboard will be available at http://localhost:8501

## Dashboard Sections

### Launch Dashboard

Visualizes SpaceX launch data including:

- Launch success rates over time
- Timeline of all launches
- Payload distribution by launch
- Core reuse metrics

### Payload Dashboard

Displays information about payloads including:

- Payload type distribution
- Orbit distribution
- Payload mass by type
- Delivery success rates

### Starlink Dashboard

Shows Starlink satellite data including:

- Orbital status distribution
- Velocity status distribution
- Satellite version breakdown
- Height vs. velocity scatter plot
- Geographic map of satellite positions

## Data Source

The dashboard connects to Snowflake and queries the following fact tables:

- `PBL_SPACEX_DATA_FCT_LAUNCH`
- `PBL_SPACEX_DATA_FCT_PAYLOAD`
- `PBL_SPACEX_DATA_FCT_STARLINK`

These tables are generated by dbt models in the SpaceX data pipeline.
